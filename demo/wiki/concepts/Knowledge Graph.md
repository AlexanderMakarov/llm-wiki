# Knowledge Graph

## Key Facts

- Is a core feature generated via AI-powered graphify with automatic community detection and hyperedge attachment. [[2026-08-10-00-quickstart-walkthrough]]
- Is constructed through a pipeline of tree-sitter AST extraction for code, semantic analysis for docs, Leiden community detection, and god-node analysis, invoked via the `graph` command. [[2026-08-10-cli-reference-03]]
- Can be queried through commands including `consolidate-topics`, `query`, and `all`. [[2026-08-10-cli-reference-07]]
