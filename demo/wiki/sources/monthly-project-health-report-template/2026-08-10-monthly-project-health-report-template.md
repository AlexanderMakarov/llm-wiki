## Summary

Created a comprehensive monthly health report template for [[llm-wiki]] that standardizes metrics collection and reporting across eight key areas: adoption (GitHub stars, forks, downloads), issues, pull requests, contributors, releases, test suite performance, and demo site uptime. The template includes specific data collection instructions using GitHub Insights, the `gh` CLI, PyPI stats, and Lighthouse audits, with guidance on publishing results to GitHub Discussions, internal docs, or blog posts.

## Key Claims

- The template defines metrics across 8 major dimensions: adoption, issues, PRs, contributors, releases, tests, demo site, and feature requests
- Data collection primarily relies on GitHub Insights and the `gh` CLI for activity metrics, with PyPI stats and Lighthouse for external metrics
- The template supports three publication venues: GitHub Discussions for public transparency, private internal documentation for stakeholders, and blog posts for milestone announcements

## Key Quotes

> "Copy this template at the start of each month. Fill in the numbers from GitHub Insights, the issue tracker, and PyPI stats." — Establishes the monthly cadence and core data sources.

> "**GitHub Insights:** repo page > Insights > Traffic, Contributors, Community" — Concrete instruction showing the primary data collection method.
