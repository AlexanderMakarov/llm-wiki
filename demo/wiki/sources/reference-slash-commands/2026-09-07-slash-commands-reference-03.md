## Summary

This reference documentation describes three [[llmwiki]] slash commands for managing the wiki build and sync process. `/wiki-build` wraps the Python build module to regenerate the static [[Static Site]], while `/wiki-all` orchestrates the complete pipeline (sync → synth → build → graph → lint) in a single command. The documentation clarifies that AI-consumable exports (llms.txt, sitemap.xml) are generated during build, and describes CI integration via the `--strict` flag.

## Key Claims

- `/wiki-build` wraps `python3 -m llmwiki build` and regenerates the static site, optionally to a custom output path
- `/wiki-all` runs all pipeline stages (sync → synth → build → graph → lint) by default unless explicitly skipped with flags like `--no-synth`
- AI-consumable exports are generated by the build stage, not as a separate pipeline step
- The `--strict` flag converts lint warnings to non-zero exit codes, enabling CI integration with [[GitHub Actions]]

## Key Quotes

> "Every stage runs unless you opt out of it." — describing `/wiki-all`'s default behavior

> "AI-consumable exports (llms.txt, sitemap.xml, etc.) are written by build, not a separate step." — clarifying architectural ownership of export generation

> "Pass --strict to turn any lint warning into a non-zero exit, which is exactly what CI wants." — CI integration pattern for strict validation
