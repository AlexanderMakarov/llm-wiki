## Summary

Defines the page type vocabulary in [[llmwiki]], owned by `llmwiki/schema.py`: five knowledge kinds readers search by (`source`, `entity`, `concept`, `project`, `synthesis`) and two system kinds the build and query workflow emit (`navigation`, `context`). Details frontmatter requirements, field provenance (who writes what: synth, harvest, build, human), and the structure of `source` pages with demo file examples. Clarifies that session metadata fields (sessionId, started, ended, etc.) are never copied from raw transcripts to wiki source frontmatter.

## Key Claims

- The page type vocabulary is centralized in `llmwiki/schema.py` and validated by both lint (`frontmatter_validity`) and the `wiki_search` [[MCP Server]] filter against the same list.
- [[Wiki Synthesis]] writes exactly 8 fields to source pages: `title`, `type`, `tags`, `date`, `source_file`, `project`, `model`, `last_updated`.
- Session metadata fields (slug, sessionId, started, ended, cwd, gitBranch, permissionMode, etc.) are written by convert to raw transcripts but never copied to wiki source pages.
- Lint requires only `title` and `type` in frontmatter (`frontmatter_completeness`); all other fields are optional or contextual.
- The `slug` field determines wiki page filenames via `synth_page_filename` but is not included in wiki frontmatter itself.
- Page `type` is read from a controlled vocabulary; invalid types trigger lint errors.

## Key Quotes

> "The vocabulary is owned by `llmwiki/schema.py`: five knowledge kinds a reader searches by (`source`, `entity`, `concept`, `project`, `synthesis`) and two system kinds the build and query workflow emit (`navigation`, `context`)."

> "One page per raw file, under `wiki/sources/<project>/`. Synth writes it from a session transcript or an added document. The body is a summary, claims, quotes, and `[[wikilinks]]` — not a copy of the transcript."

> "Convert (and the demo session generator, for `agent`) writes them on the raw transcript; `_build_source_page` does not copy them."
