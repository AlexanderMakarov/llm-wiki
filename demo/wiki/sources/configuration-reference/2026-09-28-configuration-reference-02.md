## Summary

This documentation covers the llmwiki command-line interface subcommands that implement the full wiki pipeline: `sync` converts session transcripts with configurable filtering, `build` compiles the static site and exports AI-consumable formats, `graph` generates the knowledge network, `lint` validates cross-reference integrity, and `all` orchestrates the complete workflow. A key design decision ensures link integrity checking and page materialization use the same threshold (`--min-refs`) to avoid reporting deliberately declined cross-references as defects.

## Key Claims

- The `sync` command's `--since` flag enables per-run date filtering that overrides durable adapter and filter settings (issue #192), allowing temporary lookback windows independent of stored state.
- The `build` command generates AI-consumable exports (`llms.txt`, `llms-full.txt`, `graph.jsonld`, `sitemap.xml`, `rss.xml`, `robots.txt`, `ai-readme.md`) as part of the standard build step; no separate export subcommand exists.
- The `lint` command implements a three-way threshold gate for link integrity: targets mentioned by no pages are flagged as dangling, those mentioned by fewer than `--min-refs` distinct sources are deliberately unmaterialized (not reported), and those meeting the threshold but lacking a page are reported as missing gaps.
- The canonical threshold value (`--min-refs`) is stored in a single location (`llmwiki.vault_settings.DEFAULT_MIN_REFS`) and shared between the page materialization harvest and the link_integrity validation rule, preventing drift between which pages are created and which missing links are reported.
- The `all` command runs the complete pipeline (sync → synth → build → graph → lint) with per-stage opt-out flags, replacing need for manual orchestration of interdependent steps.

## Key Quotes

> "There is no separate `export` subcommand." — design decision to emit AI-consumable formats directly from `build`

> "The stock value lives in one place, `llmwiki.vault_settings.DEFAULT_MIN_REFS`, which the harvest reads too, so the step that declines to create a page and the check that reports the missing page cannot drift apart." — ensures link_integrity aligns with harvest materialization decisions

> "Nothing is hidden permanently — the lower threshold always brings them back." — users can audit deliberately-declined cross-references by adjusting `--min-refs` downward
