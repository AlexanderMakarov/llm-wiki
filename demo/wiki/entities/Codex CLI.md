# Codex CLI

## Key Facts

- OpenAI's coding tool and one of seven supported agents in llmwiki. [[2026-08-10-multi-agent-setup]]
- Designated as a core adapter that auto-detects on every sync, without requiring explicit activation. [[2026-04-12-adapter-registry-refactor]]
- Sessions can be integrated into llmwiki to build searchable repositories of multi-agent transcripts. [[2026-08-10-04-use-with-codex-cli]]
- Functions as an MCP client capable of consuming the wiki via the MCP server interface. [[2026-07-18-mcp-server-tools]]
- Serves as an alternative execution environment for Agent mode operations in llmwiki. [[2026-08-10-mode-b-agent]]
